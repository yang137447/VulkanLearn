Tone Mapping 不是滤镜，是一台虚拟摄影机

游戏里 PBR、IBL、天空、发光材质和 bloom 都在 linear HDR 空间里工作。 Tone mapping 的任务，是把这个远超屏幕范围的 HDR 结果，经过曝光和压缩，变成显示器能承载的 LDR 颜色。

对当前项目来说，最重要的升级不是一口气支持十种风格，而是先把 exposure、bloomStrength 和一个靠谱的 filmic 曲线接起来。 你现在的裸 Reinhard 会比较灰，固定 bloomStrength = 1.0 又容易洗画面。

游戏里常见的接法

1 Linear HDR Lighting PBR、阴影、IBL、天空、emissive 都写入 FP16 HDR buffer。
2 HDR Post Effects SSR、体积光、DOF 等需要场景亮度的效果在 tone mapping 前做。
3 Bloom 从 HDR scene color 取亮部，模糊后按强度加回。
4 Exposure 手动曝光、EV100 或自动曝光，把画面放到合理亮度区间。
5 Filmic Curve ACES、Hable、AgX 或项目自定义曲线，处理高光肩部和暗部 toe。
6 Display Output 输出到 sRGB swapchain 或 HDR display path。UI 通常在这之后画。

更物理的那层：曝光

手动曝光

第一版推荐直接用一个 exposure 参数。 它不是风格参数，而是虚拟相机的曝光补偿。先把这个调通，画面会立刻比固定值好控。 

vec3 hdr = sceneColor + bloomColor * bloomStrength;
vec3 exposed = hdr * exposure;
vec3 ldr = ACESFilm(exposed);

EV100 相机模型

如果场景光照单位逐渐稳定，可以把曝光做成摄影参数：光圈、快门、ISO。 这更像真实相机，但前提是场景亮度别完全靠玄学填数。 

float ev100 = log2(aperture * aperture / shutterSpeed * 100.0 / iso);
float exposure = 1.0 / (1.2 * exp2(ev100));
vec3 exposed = hdr * exposure;

自动曝光

自动曝光通常会先生成 luminance mip chain 或 histogram，然后把平均亮度拉到 middle gray。 这是后续升级项，不建议在 tone mapping 还没稳定时先做。 

float targetGray = 0.18;
float exposure = targetGray / max(logAverageLuminance, 0.0001);

接入 VulkanLearn 的推荐版本

  • 保留当前 pass 顺序。 geometry + sky -> postProcess -> bloom -> toneMapping -> swapChain 这条结构是对的，问题主要在最后 shader 太简。
  • 给 tone mapping pass 加材质参数。 最小参数是 u_toneMappingParams = vec4(exposure, bloomStrength, saturation, mode)。
  • 不要手写 gamma。 如果最终 surface 是 sRGB 格式，shader 输出 linear LDR，硬件写入时会 encode。
  • bloomStrength 先从 0.08 开始。 当前 1.0 适合作为 debug 上限，不适合作为默认审美值。 
layout(set = 1, binding = 0) uniform UBOMIParamters {
    vec4 u_toneMappingParams;
};

float exposure = u_toneMappingParams.x;
float bloomStrength = u_toneMappingParams.y;
float saturation = u_toneMappingParams.z;

vec3 hdr = scene + bloom * bloomStrength;
vec3 color = ACESFilm(hdr * exposure);
color = ApplySaturation(color, saturation);
outColor = vec4(color, 1.0);

ACES fitted GLSL

vec3 ACESFilm(vec3 x)
{
    const float a = 2.51;
    const float b = 0.03;
    const float c = 2.43;
    const float d = 0.59;
    const float e = 0.14;
    return clamp((x * (a * x + b)) / (x * (c * x + d) + e), 0.0, 1.0);
}

vec3 ApplySaturation(vec3 color, float saturation)
{
    float luma = dot(color, vec3(0.2126, 0.7152, 0.0722));
    return mix(vec3(luma), color, saturation);
}

调试顺序

1. 先关 bloom

把 bloomStrength 设为 0。确认纯 scene HDR 经过 exposure + tonemap 是否舒服。

2. 调 exposure

让主体材质落在合理亮度，别先靠 bloom 或 saturation 救画面。

3. 再加 bloom

从 0.05 慢慢加，直到高光有呼吸感但不糊成白雾。

4. 查颜色空间

albedo / emissive 用 sRGB 采样，normal / roughness / metallic / AO 用 linear。这个项目的 texture JSON 已经有 colorSpace 字段，应继续保持。

5. 最后才调风格

风格最好放到 saturation、contrast、LUT 或 color grading。Tonemapper 先稳定，不要让它承担所有审美职责。
