## 1. 定位与已确定的范围

制作一件带经典支架的艺术地球仪，通过实时 3D 渲染表现起伏地形、海洋、
冰雪、云层和水汽变化。核心是整件摆件的造型、材质、光照和运动气质。

用户已明确：

- 保留传统地球仪的实体支架，支架风格偏经典，与鲜活的数字地球形成对比。
- 地球具有可以感知的地形起伏，需要考虑南北极、冰雪以及水汽变化。
- 优先保证整体艺术效果，不需要放大查看地表或地形细节。

本文提出但尚未最终定稿：

- 经典黄铜子午环、短车削立柱与深色胡桃木圆盘底座。
- 深灰摄影棚式展示环境、克制的冷暖材质对比。
- 地球独立自转，支架静止；另提供观察整个摆件的环绕操作。
- 冰雪月份变化、时间轴与水汽流线作为后续增强项，先完成完整静态画面。

### 首版边界

固定在完整摆件到球体整体的观察距离，限制最近缩放距离。
地球采用桌面缩比表达；引擎世界长度继续遵守厘米约定，
科学量的高度、半径和大气厚度需通过明确比例换算。
地形夸张是展示参数，不把夸张后的比例宣称为真实地球尺度。

首版不做球面分块 LOD、地表漫游、虚拟纹理、全球地理信息平台、
真实天气预测或气候模拟。厚体积云、冰体内部散射和冰下地形切换暂不作为完成条件。

## 2. 视觉设计

### 2.1 支架与构图

- 一条经典子午环沿两极连接转轴，刻度细密但不抢眼。
- 球体轴线略微倾斜，环与地球之间保留足够间隙，容纳最大地形与云层高度。
- 支架从侧面与背面承托，尽量不遮挡主要大陆；轴帽、连接件和装配关系可信。
- 黄铜温润、轻微氧化、局部抛光；木质底座深沉、半哑光。
- 不使用繁复齿轮、宫廷雕花或多重天球环。
- 16:9 主展示构图，整个摆件占画面高度约 80%，球体约 55%～60%。
- 完整露出底座与接触阴影，地球仪本身是第一视觉主体。

黄铜与胡桃木是首选探索方案；在建模前用概念图确认比例与材质组合。

### 2.2 地球表面

- 大陆轮廓可信，地形适度浮雕化，山脊与山谷由侧光建立层次。
- 地形起伏保持自然连续，避免大陆像厚板拼贴或山脉变成尖刺。
- 海面保持独立球面，海陆遮罩控制覆盖与材质，处理岸线交界。
- 雪、裸冰、海冰和白云需要不同的粗糙度、色调或空间高度。
- 南极表现为冰盖覆盖的大陆；北极点周围表现为海洋与海冰，不虚构北极大陆。
- 不添加政治边界、地名和传统经纬网格。

### 2.3 云、水汽与大气

- 薄云缓慢运动，优先保证大陆清晰和地表云影。
- 云层保留独立高度，避免像白色贴纸粘在球面上。
- 大气边缘薄而克制，不把地球包成强发光球，也不让光晕覆盖支架。
- 水汽使用低强度、可切换的可视化；流线需明确代表风或水汽输送。
- 如果使用程序化流场，标明艺术化演示，不宣称真实气象。
- 水汽不是可见白云，两个图层分别设计。

### 3.1 最小技术路线

1. 使用固定精度静态球面网格，不新增 `terrain` 场景对象类型。
2. 地形高度调节优先评估现有顶点求值；只做固定造型时也可离线烘焙几何。
3. 高程位移要同步设计法线、阴影、包围盒与最大允许夸张幅度。
4. 陆地、海面、云壳按职责拆分，避免过多紧贴的透明球壳。
5. 大气先验证简化球壳方案的观感；需要光路积分时再引入专用 Pass。
6. 云影通过明确的云遮蔽采样接入，不能假设普通透明云会自动投射正确阴影。
7. 同心透明层显式设计绘制/合成顺序，并正确处理实体支架的深度遮挡。
8. 数值和资源更新沿用现有 GT/RT 所有权边界，UI 回调只产生请求。

### 3.2 灯光是一个需要先验证的决策

地球昼夜光照与支架的展示光需要协调。第一版先尝试共享方向光、
环境照明与材质调校，观察是否已满足画面目标。

若要让地球遵循太阳方向，而支架独立接受摄影棚补光，需要验证并设计光照控制范围，
不能假设当前引擎已经支持逐对象灯光分组。支架是否在地球上投影也需要用样片比较：
保留可以强化实体感，过重则会干扰大陆与天气表现。

## 4. 数据与资产准备

建议场景名为 `SC_artistic_globe`，最终名称在实施时确定。
资产放入 `config/config.json -> resourcePath` 指定的资源仓库，
按场景组织 Meshes、Materials、Textures 和 Source；生成物放入 `Generated/`。
本次只保存计划，不创建资源目录或修改运行配置。

| 数据/资产 | 用途 | 首版处理 |
| --- | --- | --- |
| 支架与底座模型 | 经典造型和落地感 | 必需 |
| 地表颜色 | 植被、荒漠与陆地细节 | 必需，避免烘入明显云影和日照 |
| 高程与法线 | 浮雕轮廓和山脉细节 | 必需，确认精度与海平面基准 |
| 海陆遮罩 | 独立海面和岸线 | 必需 |
| 冰盖、雪、海冰遮罩 | 区分覆盖类型 | 首版静态，时间序列后置 |
| 云覆盖/密度 | 云壳与云影 | 第二阶段 |
| 风场、水汽 | 可视化与动画 | 可先程序化，真实数据接入另行验证 |

ETOPO、Blue Marble 和卫星云/水汽产品是候选数据来源，不在本文冻结具体版本。
接入前确认许可、分辨率、缺测处理、时间含义与地图投影。
高程要区分冰面与冰下基岩，避免把冰面高程再次叠加冰厚。
全部图层统一经纬度方向、经线接缝、南北极与纹理行方向约定。
月度图像可用于季节展示；简单纹理混合不能宣称恢复连续真实天气过程。

## 5. 实施阶段与验收

各阶段独立产出可展示画面。除本次文档整理外，下面项目均尚未实施。

### P0：概念与比例确认

- [ ] 用文末提示词生成完整摆件概念图。
- [ ] 确认支架造型、球体/底座比例、主观察角度和黄铜/木材组合。
- [ ] 确认地形、大气、云层的夸张程度。

验收：缩小到普通窗口观看时，能清晰读出经典支架与鲜活地球的对比。

### P1：完整静态摆件

- [ ] 建立支架、底座、球体和展示环境。
- [ ] 完成浮雕地形、海面、静态冰雪和材质。
- [ ] 固定相机、曝光、光照，完成整体构图与接触阴影。
- [ ] 验证所有允许观察角度的环体间隙、接缝和地形轮廓。

验收：关闭天气特效后，摆件本身仍然完整、可信且好看。

### P2：天气空间感

- [ ] 加入克制的大气边缘、薄云和地表云影。
- [ ] 完成云层慢速运动、暂停和复位。
- [ ] 处理地球、支架、云与大气的遮挡和合成。

验收：旋转观察时无明显透明顺序跳变、光晕穿透支架或云影脱离球面。

### P3：观赏交互与水汽

- [ ] 支架固定，球体绕自身轴转动；提供整个物件的环绕观察。
- [ ] 限制缩放距离，支持重新取景。
- [ ] 加入可切换、低强度的水汽/风场可视化。
- [ ] 如需要月份变化，加入统一时间控制与冰雪、云层的图层状态管理。
- [ ] 控件保持少量、收敛，支持隐藏后纯观赏。

验收：UI 操作不会同时误触地球旋转，各状态可暂停并可恢复到固定展示状态。

### P4：按画面缺口增强

只有 P1～P3 的整体效果需要时，再评估厚体积云、时间重建、
更复杂的大气散射、真实气象序列或高级冰材质。
不因概念图中出现某个细节就默认扩展引擎基础设施。

## 6. 验证与完成条件

- 固定相机、曝光、光源、分辨率，分别查看颜色、法线、粗糙度、阴影和最终输出。
- 对比正面、背面、两极与低角度观察；检查子午环与球体、云层的间隙。
- 检查地形最大夸张值、海陆交界、冰雪覆盖与贴图经线接缝。
- 冻结天气/时间后截图，确保视觉回归可以重复。
- 实施时按 [测试契约](../../contracts/testing.md) 选择最近的模块套件，
  不增加运行时测试旗标，不把观赏截图伪装成数值正确性证明。
- 在目标机器的优化构建中记录分辨率、帧耗时与显存占用；
  性能预算在开工前确认，当前不承诺未经测量的 FPS。

首版完成条件：支架完整且经典，地球起伏可辨，海洋与冰雪清晰，
薄云和大气不遮挡主体，转动平稳，整件作品可以在普通观赏距离下成立。

地表呈现绿色植被、浅色荒漠、灰褐色山地的丰富自然层次。
海洋具有深蓝色与海岸浅青色的变化，带柔和真实的太阳反光。海面完整、平静，不要全球尺度可见的巨大海浪。
