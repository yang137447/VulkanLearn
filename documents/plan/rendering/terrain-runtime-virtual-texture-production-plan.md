# 地形 RVT 按需生产方案与独立复核

> 状态：设计提案，尚未实现。2026-11-20。本文只规定下一轮实施与验收，不替代当前契约。
> 工作树：`terrain-openworld/VulkanLearn`；禁止以主 checkout 的旧地形实现作为现状证据。

## 1. 结论与范围

完整飞马岛不需要预先生成全部 18.08 GiB（19.42 GB）合成页，才能使用完整地形。
推荐把 Editor 已有的 GPU 合成能力接入 Game 的缺页生产链：
**发布生产输入与少量粗页，运行时按可见需求生成细页，所有地块共享有界物理缓存。**

这次调整的关键是生产与资源生命周期，不是先把全部页压缩一遍。
基础材质仍然只采样合成页；不恢复旧层源 VT、旧基础层直接评价或兼容材质开关。
完整岛的几何、覆盖和可达范围保留；缓存为空、相机到达未访问位置时也必须能生成正确内容。

本轮交付是方案及复核。实际实现、资产重发布与最终视觉验收由下述阶段约束。
原生命周期计划的已完成项保留为历史；其中“完整页包是运行前提”的设计由本提案提出替换，
不能据此宣称当前 Game 已经具备 RVT 生产能力。

## 3. 地址与 mip 决策

保留 16 个 surface 的现有虚拟地址、placement 与反馈编码，
把三通道物理池、生产 scratch、上传环和调度器移到 World 级共享。
不以前置合并成 32768² 全岛地址域来扩大本轮改造。
池内以 `(surfaceId, mip, x, y, contentIdentity)` 区分内容。

虚拟 mip 保留：近处请求更细的页，远处请求更粗的页；
页在物理池中的存储尺寸保持 136²。远处缩小的是所需虚拟分辨率与页数量。
物理 atlas 不使用普通整图 mip，避免相邻槽串色；border、祖先回退与两级虚拟 mip 采样继续显式管理。
原始 tiling 纹理仍按自身 footprint 使用源 mip。

每个 surface 至少保留一个可用的粗根页，先发布有效根页再开放该 surface 绘制。
根页来自随包粗页；其损坏且生产输入有效时可重建，重建完成前等待就绪，不展示未初始化材质。
可另发布 mip4…13 粗页集以改善冷启动，但仅根页强制驻留，其余与细页一起受预算约束。
粗页范围是待测参数，不是最终固定值。
根页就绪仅代表寻址安全，不代表可交互画质就绪。初次进入场景需预热初始相机的可见粗页集，
达到 P0 冻结的画质/清晰度阈值再解除加载状态；瞬移后的粗糙阶段与收敛过程单独验收。
不得把整块 1×1 根页铺色作为近景完成画面。

## 4. 各阶段资源和职责

| 阶段 | 资源 | 所有者与流向 |
| --- | --- | --- |
| Editor 作者态 | TR/MI、源纹理、宏高度、覆盖/权重、层身份、placement | 编辑服务持有；保存后形成作者 revision |
| 冻结与构建 | 输入快照、层映射、frame/coverage、生成规则和依赖摘要 | 构建器校验并导出可独立消费的运行时生产闭包 |
| 发布态 | V2 描述、生产闭包、少量粗页、独立 tiling 高度资源 | 原子发布一个完整版本；细页不要求存在 |
| Game 装载 | 包内不可变输入、shader、根页、池与页表 | Runtime 按清单装载；不扫描 Editor 作者目录，不依赖工作区 |
| 运行态 | feedback、缺页队列、生产输出、物理槽、页表 | World RVT 服务调度；GPU 产页后事务发布 |
| 本地缓存 | 可选细页及索引 | 可删除、有上限；缺失或失效回到生产，不影响世界完整性 |
| 编辑刷新 | 新快照与 dirty 页集合 | Editor 使用同一生产/发布链，额外负责作者编辑和保存 |
| 替换与退出 | 旧输入、槽、descriptor、在途任务 | generation 隔离并按 GPU epoch 退休 |

运行时生产闭包必须列举并验证：M_terrain 对应 compute shader 及 include/编译身份、
albedo/normal/ORM 与基础 height blend 所需源 mip、coverage、层 catalog、
globalId→sourceSlice 映射、局部 normal/tangent frame 或等价确定性重建输入、
placement、边界与滤波配置。动态消费者所需的 global 图、源数组和 tiling 高度也必须随包。
不能只携带依赖 hash 而不携带实际输入。

第一版延续已支持的材质、sourceSet 和 placement 限制；不顺带开放任意材质图或多 sourceSet。
不支持项在构建阶段报错，不能运行时静默改用旧路径。
第一版明确保留现有 normal/tangent frame 输入并计入预算，不前置替换为宏高度差分算法；
之后若重建，必须先与既有 mesh 插值基作误差验证。`LocalLayerArray` 模式的
`layerWeightMaps`、local→global 映射与采样配置纳入生产闭包，
不未经等价性验证就压平为 top4 coverage。
`weightSource`、当前权重 overlay 合并后的冻结结果或其可重放数据也属于闭包；
Game 初始化须实际创建这些输入，exporter 的 runtime compute 清单必须包含
`terrainCompositedBake.comp` 及其编译产物。独立离线 Game 分别验证两种权重模式，
不能只用 coverage 模式的成功代替全部支持范围。
全局 coverage 与生产 coverage 共用一个受版本管理的资源所有者；
Editor 用不可变快照/写时复制保护在途读，取消稳定态每 surface 的重复覆盖副本。
快照替换期间的短暂双份资源计入重叠预算。

## 5. 生产与发布事务

1. feedback 请求两个虚拟 mip；CPU 去重后按可见性、粗祖先缺失、等待时间排序。
2. 查询驻留页、可选本地缓存、随包粗页；未命中且输入有效时进入 GPU 生产。
3. 请求携带 World generation、surface revision、content identity 和完整页键。
4. 获取生产 slot、冻结输入强引用和候选物理槽；已有有效页继续供采样。
5. `Record` 写 GPU buffer，经 compute→transfer 屏障复制到三个 atlas 通道。
   不把完整页 readback 到 CPU 后再上传。首版复用 RGBA8，压缩不是依赖项。
6. 读取小型 status 并等待对应 fence 完成；status 非零、身份过期或提交失败均不得发布。
   三通道复制成功后，在后续安全提交点发布页表；采样屏障、跨提交可见性须显式覆盖。
7. 页表切换成功才转为 Resident；旧槽必须等引用它的 GPU epoch 结束再复用。
8. 淘汰细页前保证有效祖先；相机移动不进行全 World waitIdle。

状态至少包括 Absent、Queued、Producing、AwaitingFence、ReadyToPublish、
Resident、FailedBackoff、Stale；无覆盖是确定内容语义，不能与“尚未生成”混同。
错误分类区分可再生产的缓存损坏、暂态生产失败和不可恢复的生产输入损坏。
暂态失败采用有上限重试与退避，禁止每帧无限重试；不可恢复错误需可诊断并终止候选装载或明确报告故障。
GPU buffer 与物理槽预算不足时排队/降级至已有祖先，不能突破预算或发布半页。

候选槽即使暂时无页表引用，写入失败后仍需等提交完成才能复用。
GPU status 是现有 evaluator 的发布前提，不能为省一次小 readback 而省略。
当前 Baker slot 只有一份参数 buffer 与 descriptor set，不能同帧多个页重复覆盖同一 slot。
P2 为每个在途页分配独立参数、descriptor 与输出区间（帧环×每帧最大生产页数），
或者使用经验证的动态偏移方案；相关提交完成前不可改写。
物理槽采用 Free→Reserved→Resident→Retiring→Free 状态：
只有 Free 槽可被新任务预留及写入，Resident/Retiring 槽禁止覆盖。
淘汰先将该页表项置无效，由 shader 逐级查找可用祖先并按祖先 mip 计算坐标，
再等待旧引用 epoch 完成；现有编码不支持将当前 mip 表项直接填成祖先槽。
验收覆盖跨 mip 回退与旧帧退休。保留有界 Free 水位，
根页和预留槽均占总池容量，满载时暂停派发并公平排队，验证无永久饥饿。
status/fence 采用异步轮询，未完成则沿用祖先，不进行逐帧同步等待。
生产输出、参数、descriptor、冻结输入和读回槽保活至对应提交完成；
显式处理非 coherent 内存 invalidate/flush、compute→copy→shader read 屏障和 image layout。
页表提交前再次检查身份；状态注入测试覆盖非零 status、迟到 revision、提交失败和槽复用竞争。

## 6. V2 发布协议与检查边界

V2 明确区分不可变生产闭包、随包粗页和可丢弃本地缓存。
虚拟布局可推导的未生成页不逐页列索引；只索引真实随包 payload。
索引至少包含版本、surface 描述、内容身份、生产输入清单与摘要、
生成器/滤波/编码规则、根页集合、实际页的 offset/size/hash。
二进制索引是否必要由实测决定，不能以换 JSON 为唯一性能方案。

启动校验版本、范围、索引结构、必要输入和根页就绪；
实际页读取时校验其 size/hash。发布、安装验证工具执行全量闭包校验。
不在每次 World 装载时同步扫描所有细页 payload。
生产输入被消费前必须验证，不能把“不扫细页”扩展成“不验证生产输入”。
这一检查时机变化必须写入新契约与测试。

写入采用临时内容寻址对象→完整验证→原子切换顶层发布指针；
失败不改变上一份发布。只读安装目录与可写本地缓存分离。
缓存键含生成器、编码、输入身份及页键；配置不一致直接失效。
不把旧 V1 完整页包解释为 V2 稀疏包；生产运行时不保留 V1 自动回退。
确需迁移工具时作为独立离线工具，不进入 Game 加载分支。
V2 解析保留严格安全约束：拒绝重复 surface/页键、越界 mip/坐标、
整数溢出、offset 重叠/越界、格式与尺寸不符、缺失/重复根页、
路径逃逸和链接替换。只放开合法缺页，不放松实际 payload 与路径校验；
每类错误均需负例。生产闭包损坏明确失败，可丢弃缓存损坏允许重建。

## 7. 近场 tiling 置换及动态项

保持现有独立、小体积的常驻 R16 tiling 高度 atlas 与层映射，
TES 按 `weightSource` 选择权重路径：CoverageAtlas 模式使用 coverage top4；
LocalLayerArray 模式从逐层权重 overlay 解析 top4，并经 local→global 映射。
两种模式分别驱动与验收置换，不依赖基础合成色页是否驻留。
这份高度资源可以归入 RVT 发布清单与统一预算，但生命周期独立于易被淘汰的基础材质细页。
粗根页可用不代表 TES 高度已就绪；高度闭包就绪是近场置换启用的独立条件。

本轮不把近场 displacement 硬塞入三通道 RGBA 基础页，也不改变宏高度几何和碰撞来源。
基础页继续存 albedo、局部 normal、ORM；detail、macro、global 和距离淡出保留当前动态评价。
基础 height blend 的冻结规则继续计入内容身份，不能把依赖相机的淡出烘进长期缓存。
因此源数组仍有实际消费者，不能承诺本轮会删除全部源纹理常驻成本。
TES 高度使用 mip2；非零基础 height blend 还消费源高度 mip3 和层 displacement 值。
高度修改若影响后者，必须使相关基础页及其祖先失效；仅能证明基础输入不变时才跳过。
近场验收必须处于实际位移生效的距离、coverage 与参数下，
缺失高度需拒绝或明确停用并报告，不能用中性值截图冒充置换通过。

## 8. 编辑刷新与资源替换

Paint 使相交页、涉及 border 的邻页及全部受影响祖先失效；
跨 surface 接缝按真实覆盖依赖传播，不只刷新当前地块。
Sculpt 同时更新宏几何、frame、碰撞与受影响合成页；
只改 tiling 高度时刷新独立高度资源及其消费者，不无条件重烘全部基础页。
基础层材质、源图、层映射、滤波和生成器变化依据依赖图升级身份。
纯动态 detail/global/TES 参数变化只更新对应消费者。

revision 变化后旧任务只能退休，不能写入新页表；
新根页与必要输入准备完成后再提交候选资源集。
不能以同一个页键让新旧身份混用。保存作者态、预览刷新、发布游戏版本是三个明确动作，
预览成功不能自动标记游戏发布为最新。
shader 热重载、World 重载、撤销重做和设备资源重建使用相同身份及退休原则。
连续邻块需显式登记邻接与材质/覆盖映射，border 通过该关系读取真实邻块输入；
外部世界边缘继续 clamp，非连续放置不凭坐标相邻推断连接。
现有 bake 的单 surface clamp 不能直接用来满足跨块 border，
只增加 dirty 通知也不能解决这一问题。P1 定义跨块输入闭包，P3 实现寻址，
并在不同层映射、LocalLayerArray、混合权重和四块角点下验证。
历史截图中的硬边仅是待定位现象，不预先认定其根因。
邻接协议包含双方坐标变换与不同 placement 的输入映射，粗 mip 积分 footprint
跨界也走邻接读取，不能仅处理 mip0 border。作者数据本身不连续须另报诊断。

## 9. 预算与性能验收方法

预算必须是 World 级可配置硬上限，分开记录：
三通道共享池、每 surface 页表、coverage、源纹理、frame 输入、常驻高度、
生产 scratch、反馈与 status readback、上传环、CPU 队列、缓存索引和替换重叠。
共享池按格式组分配；Full16 首版只有一种三通道组合。
CPU/GPU 入场检查和运行中峰值统计必须用同一口径，不能漏掉全局与私有 coverage 的重复。
每 surface 不再保留完整 staging 环；生产/上传环受 World 在途数约束。
预算分为 RVT 缓存/工作区上限、共享生产/动态输入上限及地形总上限；
三者关系和替换瞬间允许的总量在 P0 冻结为配置，源纹理不能游离于总账外。
不直接沿用旧服务的 1 GiB 为新总账，也不通过默认放大预算掩盖重复分配。
normal/tangent frame 首版保留；其约 128.5 MiB 的 Full16 格式算术需按实际尺寸核对计入。
RGBA 生产输出按每在途页至少 221,956 B（含 4 B status）计，
再加参数、descriptor、对齐与驱动分配开销，不能只用磁盘页大小估计 scratch。
World 替换若双份输入超过总上限，应拒绝候选并保留旧 World 或采用经验证的分阶段复用；
不允许候选准备静默突破峰值预算。
总准入在跨 World 的服务/后端资源所有者处执行，新旧 World、在途帧与退休资源合计，
不能只检查两个各自达标的 World。候选失败必须释放候选并保持旧 World 可用。
可见工作集超过槽数时提高有效目标 mip，按优先级/等待时间公平调度并加滞回避免抖动；
“收敛”按预算下明确报告的有效目标定义，不保证所有原始细 mip 同时驻留。
验收冻结画质下限；超出能力则明确报告预算不足，不能无限降低 mip 后声称通过。

P0 实测并记录：硬件/驱动、分辨率、构建模式、源闭包大小、
冷/热启动各阶段、连续运行峰值、清空缓存后的相机路径。
旧报告只作参考，最终比较必须在同机器同场景同路径同构建条件重新采集基线。
正式性能阈值在 P0 测量记录中冻结，后续不得边验收边放宽。
生产每帧页数、GPU 时间、字节与在途任务均有上限；GPU 时间用 timestamp 测量，
CPU 提交耗时不冒充 GPU 生产耗时。单页不可抢占的最坏生产时间也需测量与约束。
P0 须补齐基础地形采样、TES 所在绘制阶段及 RVT 生产/复制的 GPU timestamp 覆盖；
区分绘制阶段整体耗时与能独立测到的子阶段，不能用部分 passes 总和声称完整地形耗时。
冻结记录还必须列出冷缓存清理范围、目标/有效 mip、首帧画质、收敛时间、
整进程 CPU 与 WDDM GPU 峰值，以及与同条件基线的改善要求；这些是 P0 的必交项。

压缩只作为后续可选阶段：先验证编码误差、吞吐、硬件格式支持及峰值内存，
再比较节省的带宽是否覆盖成本。BC5/BC7 输出需合法 block 编码与 copy 路径，
不能假定 BC image 支持 storage 写入。没有实测就不承诺压缩后包大小。

P1/P2 接口可以并行设计，实际集成必须以 P3 完整冷缓存生产闭环为准；
不以“Store 支持 sparse”或“compute 能输出单页”宣告 RVT 完成。
每阶段由执行 subagent 实现，另一个未参与该阶段实现的 subagent 验收；
主线程负责接口、预算、证据与最终整合。

最终验收至少包括：远景全岛、近景、地块接缝与四角、连续跨块、
快速移动与瞬移、冷/热缓存、缓存删除/损坏、输入损坏、
超预算、生产失败、World 替换、在途编辑刷新、两种线程模式和独立离线游戏包。
视觉比较锁定相同输入/相机/渲染参数，与现有基础 evaluator 对比基础页，
另验动态项与 TES；保存图像、误差指标和实际引用页的身份。
退出条件是正确性、性能阈值和资源上限同时达标，不能只交截图。

P5 精确清退清单：V1 全 mip 强制完整索引和启动全 payload 扫描、
每 surface 独立 runtime/atlas/staging、Editor 预览整页 CPU readback→再上传链、
exporter 的全量页闭合断言、旧 TR 发布配置与默认场景引用。
新 V2 包与独立 Game 验收成功后，删除资产工作树中被替代的 19.42 GB 旧发布产物；
历史日志与测量证据保留。测试专用数值读取不算生产预览路径。
同步更新导入器、契约、打包规则和架构门禁，并为旧 V1 配置、旧材质开关建立拒绝负例。

## 11. 独立方案与复核记录

本轮两个有效独立方案均核对 `terrain-openworld` 工作树：
Kant 主张“少量粗页 + 运行时细页生产 + 完整生产输入”；
Hegel 提出压缩、共享资源及索引优化，交叉复核后将压缩移出 RVT 主线。
另一份曾读取主 checkout 的报告已排除，其关于旧 layer VT 的现状结论不得进入本提案。

主线程综合裁决：

- 采用真正的缺页生产；否决“先压缩全部页即可完成 RVT”。
- 保留现有 surface 地址域；否决为节省少量粗页而前置改造全岛反馈协议。
- 首版 RGBA8；否决以尚不存在的 BC 编码器作为完成条件。
- 共享物理池与完整输入账本同时推进；否决只共享调度却声称已共享显存。
- 保留虚拟 mip 与独立 tiling 高度资源；不要求把全部粗页钉在显存。
- 所有启动、编码和收敛速度须实测；撤除缺乏证据的压缩率与耗时保证。

独立复核闭环：

| 审阅者 | 首轮发现 | 修订与结果 |
| --- | --- | --- |
| Hegel | 同帧参数覆盖、frame/coverage 预算、邻块输入、槽退休、GPU 计时与 V1 清退 | 全部补入；复审通过，无剩余设计阻断，可进入 P0/P1 |
| Kant | Game 生产闭包、异步 GPU 同步、V2 安全校验、跨块 footprint、高度依赖、跨 World 准入与收敛条件；复审补充祖先回退编码与 TES 双权重路径 | 已修订为表项置无效后 shader 查祖先，并明确 TES 按 weightSource 分流；最终复审通过，无剩余设计阻断 |

审阅通过仅代表设计可进入实施，不代替 P0 的预算冻结与后续实现验收。
实施时须核对邻接读取的 descriptor 数量/动态索引能力，
共享源纹理的跨 World 复用按实际资源身份去重计账，不能按 World 数机械翻倍或漏算私有输入。
